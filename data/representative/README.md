# Representative ETGP Metadata Subset

`etgp_metadata_subset.tsv` contains six unmodified metadata rows from the
DNALongBench ETGP dataset: one positive and one negative example from each of
the train, validation, and test splits. It is included only to document the
real input schema and is not large enough to reproduce reported metrics.

Source: DNALongBench ETGP, Harvard Dataverse DOI
`10.7910/DVN/CTEQXX`, version 1, file
`CRISPRi_EPI_K562_hg19.data.tsv` (data-file ID `10443715`).

The source dataset is released under CC0 1.0. The 450-kb genomic sequences are
not copied into this archive; retrieve the complete official dataset with
`scripts/download_dnalongbench_450k_data.py`.
